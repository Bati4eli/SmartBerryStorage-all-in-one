# Commit

Use these rules for commits in `MyCloud-Backend` and `MyCloud-AndroidClient`:

- Каждый новый файл добавлять в git сразу после его создания: выполнить `git add <path>` для этого файла до следующих правок.
- Коммиты вести на English.
- Формат: `<label>: <emoji> <краткое описание измененной фичи/механизма>` - без ковычек `<>`
- Для коммита по TODO указывать номер задачи сразу после label: только числовая часть идентификатора, без текстового суффикса. Например, для `100-autoupload`: `fix: #100 🐛 ...`; для `001.0`: `feat: #001.0 🗺️ ...`.
- Доступные `label`: `feat`, `fix`, `chore`, `refactor`, `test`, `docs`, `build`, `ci`, `perf`, `style`, `revert`.
- Если есть подходящий эмодзи, использовать его в `<emoji>`.
- После первой строки вставлять двойной перенос строки.
- Дополнительную информацию писать только по затронутым логическим цепочкам/механизмам/функциям, а не по каждому микрошагу.
- Если затронута одна логическая цепочка, писать ровно 1 пункт в body.
- Если затронуто несколько независимых цепочек, писать по 1 пункту на каждую, но не более 3 пунктов суммарно.
- Каждая строка body начинается с -.
- Для `git commit` не использовать несколько `-m` для body; передавать message одним блоком с переносами строк.
- Дополнительная информация: максимум 6 строк.
